# Output Checklist — market-landscape

送信前に確認する。1 つでも fail なら直してから出す。

## Every phase

- [ ] Research Frame（pain / user / scope / desired direction）がある
- [ ] 推測は `(前提)` / `※推測` / `要確認` が付いている
- [ ] 末尾に Gaps または Next が 1–2 行ある

## Phase 1 Survey

- [ ] 12–20 件（明示要求時のみそれ以上）
- [ ] Direct 以外（Adjacent / Informal / UX・BM Reference）が含まれる
- [ ] Cluster notes（軸の種）がある
- [ ] 個別の長文プロファイルになっていない

## Phase 2 Axes

- [ ] 候補が 2 セット以上、または 1 セット + 捨てた案の説明
- [ ] 右・上が望ましい向きだと明示している
- [ ] 汎用軸（Simple↔Feature-rich 等）を主軸にしていない
- [ ] **ユーザー確定前に Phase 3 へ進んでいない**

## Phase 3 Map

- [ ] Confirmed Axes を再掲している
- [ ] Placement table がある
- [ ] 4 象限マップ（Mermaid または ASCII）がある
- [ ] **空白の右上** セクションがある（空き判定・なぜ空か・次の検証・偽空白）
- [ ] 自プロダクト仮置き（★）がある

## Anti-patterns (fail if true)

- 競合機能比較表だけで地図がない
- 軸がカテゴリ名の列挙
- 右上が「望ましい空白」になっていない
- Phase 2 をスキップしていきなりマップ
