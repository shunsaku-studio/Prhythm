Overview

サマリー：瞬作スタジオ、Prhythm（プリズム）とは

バンド・スタジオモデルの先駆けとして瞬作スタジオを立ち上げ。瞬作スキルセット Prhythm の提供で「スジの良い瞬作」の普及を目指す。各プロダクトのバンドが提案を任されたとき、横断スタジオが型とスキルで後方支援する。

01
瞬作スタジオとは

瞬作（AIを用いた高速プロトタイピング）のスキルを組織に配る横断スタジオ

  • バンド・スタジオモデルの先駆けとして立ち上げ。各プロダクトのバンドへスキル・仕組みを供給する後方支援
  • スタジオ群の最初の一つ。「スキルを型にして配る」運営モデルが、後続スタジオ（EC／DS／a11y 等）の雛形になる
  • 現場の「何をすればいいかわからない」を、型の提供で「わかる・できる・たのしい」に変える
02
Prhythm（プリズム）とは

瞬作スタジオが最初に提供するスキルセット

  • スキルセットと使い方をセットで提供し、提案瞬作に踏み出せる土壌をつくる
  • ワークフロー自体がビジネス・UXを自然と考えさせる設計。取り組むうちに総合的なプロダクト視点が身につく
  • 速さだけでない、「中身のスジの良さ」で差別化する

瞬作スタジオ / Prhythm MD紹介03
Prhythm

瞬作スキルセット Prhythmとは

必要なのは「AIにコードを書かせるツール」ではなく、多くの人が提案瞬作に踏み出せる土壌。

Prhythm の答え

瞬作のスキルセットと提案での使い方をセットで提供する。しかもそのワークフロー自体が Creative / Advisory 側の関心事を自然と考えさせる設計になっていて、取り組むうちに総合的なプロダクト視点が身につく仕掛け

WHAT
スキルセット＋使い方ガイドを提供

何を考え、何を作り、どう協業し、どう顧客に届けるか。

提案未経験のメンバーでも成功イメージを持って踏み出せるような基礎を提供。

HOW
ワークフロー自体が視野を広げる設計

ビジネス・UX・開発・実行計画を自然と考えさせる流れで、プロダクト視点が身につく。

ただ「速くできた」ではなく、「立ち上げ期のプロダクトマネジメント」として瞬作に取り組む。

WHY IT WORKS
速さではなく中身で勝負

他社がスピードで追いついても、多面的な検討力は簡単に真似できない。

「プロダクトとしてのスジの良さ」で勝負して、Song をイケてるプロダクト組織に！

Demo Skill 02 / 08

ヒアリング

主担当：ビジネス skill: hearing-digest

市場の地図を踏まえ、顧客の言葉で事実と仮説を切り分ける。

QUESTIONS

スキルが生成する質問リスト（例）

Q1現行の社内公募は年何回・どんなフローで回していますか？

Q2応募率1.2%はどう計測していますか？部署外応募の内訳は？

Q3応募に上司の承認は必要ですか？いつ・誰に知られますか？

Q4不採用時、結果は誰にどう伝わりますか？

Q5Slack #異動相談は公募とどう関係していますか？

OUTPUT

ヒアリング結果を事実と仮説に分離

FACTS（事実）
  • 公募は年2回・書類選考制。応募率は全社員の1.2%
  • 応募には現上司の承認欄がある（気まずさの元凶）
  • 不採用時、結果が本人と上司の両方に通知される
  • Slack #異動相談 には月40件の書き込みがある
HYPOTHESES（未検証仮説）
  • core 上司に知られずに探索できれば、潜在応募者は動く
  • core 「異動」より「週1日の兼務」なら心理障壁が1/10になる
  • 受け入れ側の部署は、正式求人より「手伝ってほしい仕事」を多く持つ
WHY THIS SKILL

参考調査で見つけた空白地帯を、顧客の実態で検証する。FACTS と HYPOTHESES を分けることで、提案が「思いつき」ではなく「検証可能なストーリー」になる。

クリエイターにとっては、いきなり解を出すのではなく聞く・整理する型を身につける場。特にエンジニアにとってはデザイン態度の入口。顧客の言葉をそのまま提案の骨子に載せられるようになる。

Demo Skill 04 / 08

ビジョン・コンセプト

主担当：ビジネス skill: product-vision

ジャーニーの To-Be を、提案の核となるビジョンとコンセプトに言語化する。

VISION

キャリアの選択肢が、社内にあることが当たり前になる。

CONCEPT

「異動じゃなく、まず越境から」

ウチナカ公募は求人サイトではなく、週1日・3ヶ月から試せる「越境ミッション」のマーケットプレイス。転職級の決断を求めず、小さな越境の成功体験を積み上げる。

REJECTED（棄却案）
  • 「社内転職サイト」 — 心理障壁が As-Is と同じ。復活条件：越境経由の異動が文化として定着した後
  • 「上司推薦型マッチング」 — core仮説①（秘匿性）と正面衝突するため棄却
WHY THIS SKILL

ジャーニーマップの To-Be を一言で語れる言葉に落とす。棄却案まで残すことで、「なぜこの方向か」が提案で説明できる。

クリエイターにとっては、機能を並べる前に何を作らないかを決める型。ビジョンとコンセプトが、その後のモデリング・プロトの判断基準になる。

Vision

瞬作スタジオのビジョン

瞬作スタジオが目指すのは、組織のプロダクト力の底上げ・スタジオのお手本となること・バンドを増やすことの3つ。多面的な検討とプロトタイピングを組織に根付かせ、バンド・スタジオモデルの拡大を牽引する。

01
組織のプロダクト力の底上げ
多面的な検討とプロトタイピング

ただモックをつくるだけでなく、ビジネス・UX・開発・実行計画の各観点からプロダクトを考え、イケてるプロダクトを作れるようにする

プロダクトマネジメントの目線

提案・開発の現場に、プロダクトマネジメントの視点を根付かせ、組織全体のプロダクト力を底上げする

02
スタジオのお手本となる
最初のスタジオとして

瞬作スタジオはバンド・スタジオモデルにおける先駆け。横断スタジオ群の立ち上げ方そのものを示す

後続スタジオの雛形

「スキルを型にして配る」運営モデルが、EC・デザインシステム・a11y 等の後続スタジオに展開される雛形になる

03
バンドを増やす
スタジオが床を上げる

スタジオが増えて支援の床が上がることで、少数精鋭のバンドチームにも挑戦しやすい環境をつくる

RDEモデルのコアエンジン

その中でも瞬作スタジオは、バンド・スタジオモデル（RDEモデル）立ち上げを牽引するコアエンジンになりうる

瞬作スタジオのロードマップ
